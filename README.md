## Preguntas iniciales

1. ¿Qué significa que una prueba esté en estado ROJO?

Significa que la prueba falla debido a que aún no tenemos definida la función a probar.

2. ¿Qué debe hacerse para llegar a VERDE?

Agregar la cantidad mínima de código para hacer pasar la prueba.

3. ¿Qué diferencia existe entre agregar funcionalidad y refactorizar?

Agregar funcionalidad consiste en implementar una nueva "función/método" que no existía, mientras que refactorizar implica revisar el funcionamiento de una función y mejorarlo de tal manera que pueda ser mantenible (cambiar nombres, eliminar código repetido o cambiar la estructura interna) pero procurando mantener el mismo comportamiento.

4. ¿Por qué en TDD no conviene implementar todos los requisitos desde el inicio?

Porque al avanzar paso a paso, si surge un error, es mucho más fácil de localizarlo y corregirlo.
